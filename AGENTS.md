# Repository instructions

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/) for every commit:

```text
<type>: <short imperative description>
```

Allowed types: `fix`, `feat`, `chore`, `docs`, `refactor`, `test`, `ci`, and `build`.

Examples:

```text
fix: install Argon packages in one transaction
chore: add contribution guidelines
```

Keep the subject in English, lowercase after the type, and do not end it with a period.
